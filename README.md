**Kombudget** is an envelope budgeting app — assign every dollar to a category, then track spending against it.

[View the Demo](https://tylercorme.github.io/kombudget/) — runs in-browser, seeded with example data.

> built with [marimo](https://github.com/marimo-team/marimo).

---

## Features

**Accounts**
- Track transactions from checking, credit, and liability accounts

**Transactions**
- Import CSVs from various institutions
- Detect duplicate transactions from overlapping statement periods
- Bulk edits for categorization

**Budgets**
- Create income and expense categories
- Implement envelope budgeting with rollovers to the next month
- Set a budget start date to skip past transactions

**Reports**
- Monthly breakdown of expenses and budgeted categories
